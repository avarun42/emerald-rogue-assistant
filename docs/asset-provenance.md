# Distribution status

The original Rogue Assistant creator gave the fork maintainer direct permission
to maintain this fork and publish its GitHub releases. That approval covers the
inherited application source and project assets used by this fork. Public beta
releases are therefore an approved project activity.

This record does not create a general license for other people to modify or
redistribute the repository. The maintainer can add a repository license after
choosing suitable terms. Until then, users should not infer rights that are not
stated.

The packages include `THIRD_PARTY_NOTICES.md` and the available dependency
license texts. The bundled Pokémon Emerald Pro font identifies `crystalwalrein`
as its author and CC BY-SA 3.0 as its license. Keep those notices with every
release. Update them when dependencies or bundled assets change.
