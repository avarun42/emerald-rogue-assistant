# Post-1.0 roadmap

These items are intentionally deferred and must not appear as unowned TODOs in
production code:

- Dynamic local pairing and discovery for multiple simultaneous mGBA sessions.
- Validated support adapters for ROM Assistant APIs 1 and 2.
- An explicit process for validating future ROM Assistant API versions.
- Linux ARM64 release and packaging coverage.
- Windows x86 only if a demonstrated user need justifies the extra matrix.
- Optional application update discovery.
